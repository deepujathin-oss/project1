# ⛈️ HydroClimatic Intelligence App - India Rainfall Analytics

An advanced web dashboard engineered using **Streamlit** and **Plotly** to visualize, parse, and analyze multi-decadal geographic precipitation data across 36 sub-divisions.

## 🚀 Key Functional Capabilities
- **Executive Overview Panel:** Interactive geographical coordinate clustering maps displaying mean precipitation trends, and dynamic top wettest/driest ranking engines.
- **Regional Deep-Dive Modules:** Granular timelines evaluating a 10-year moving rolling average sequence, structural macro-seasonal distribution pies, and boxplots visualizing quarterly distributions.
- **Statistical Anomaly Engineering:** Automated Z-score normalization vectors tracking flood/drought risks alongside fitted multi-variate linear regression algorithms showing change per decade.
- **Rule-based Insight Agent:** A fully integrated Chat interface (`st.chat_input`) designed to parse queries like "drought in Punjab" or "highest rainfall in Kerala" instantly.
